# ورقة مدخلات المالك

التاريخ: 2026-10-09. اكتب جوابك تحت كل سؤال وابعتها، وأنا أحدّث الموقع وسجل الادعاءات والخطة.

**القاعدة حتى تُجاب الأسئلة:** الموقع لا يذكر عميلًا ولا رقمًا ولا تشغيلًا فعليًا ولا امتثالًا ولا شراكة. الحقائق لا أفترضها. القرارات فقط لها افتراض مؤقت للعمل، وهو **قابل للتغيير** ولا يُنشر.

| # | السؤال | نوعه | الافتراض المؤقت | جوابك |
|---|---|---|---|---|
| 1 | هل لديكم عملاء حاليون أو سابقون؟ هل يمكن نشر اسم أحدهم، أو كتابة حالة مجهولة بموافقته؟ | حقيقة | لا عملاء ظاهرون، ولا قسم "عملاء" في الموقع | |
| 2 | كم مطورًا ينفذ؟ كم ساعة متاحة شهريًا؟ من يتولى المبيعات؟ | حقيقة | مجهول. الخطة تُكتب بمسؤول "مطلوب تحديده" | |
| 3 | هل Rveta وWasal وChix وBusaty تعمل فعلًا مع مستخدمين؟ منذ متى؟ | حقيقة | لا تشغيل فعلي. تبقى صياغة "صممنا وبنينا" | |
| 4 | هل Odoo خدمة حقيقية؟ شراكة رسمية؟ مشاريع سابقة؟ | حقيقة | لا شراكة. تبقى كـ"بيان مالك" في السجل ولا تُعرض كميزة | |
| 5 | ما أقل مشروع تقبلونه، وما هامش الربح المستهدف؟ | قرار | الأقل ما يغطي مراجعة تقنية مدفوعة. لا أرقام في الموقع قبل 3 عروض مقارنة | |
| 6 | ما المقصود بـ NEXA؟ وأي منافس آخر تريد مقارنته؟ | حقيقة | لا مقارنة لـ NEXA | |
| 7 | أين الملفات `AGENTS.md` و`/workspace/market-research/...`؟ | حقيقة | تُعتبر غير موجودة | |

## ما سأفعله بعد كل جواب
| الجواب | التغيير |
|---|---|
| 1 نعم | قسم حالة عمل مجهولة أو اسم عميل بموافقته، وصف `CLAIMS_REGISTRY` بالدليل |
| 2 | أسماء المسؤولين وساعاتهم في خطة الـ 90 يومًا، ومعايير نجاح واقعية |
| 3 نعم، بدليل (مراقبة أو أرقام توافق عليها) | أعيد "نشغّل" لما ثبت فقط، وأضيف الدليل للسجل |
| 4 نعم | أنقل خيار Odoo إلى صدارة القرار وأكتب عرضه |
| 5 | سعر "المراجعة التقنية" وأقل نطاق في العرض الأولي |
| 6 | أضيف المنافس لجدول المقارنة بعد فتح الدومينات |
| 7 | أقارن الدراسة بخطتكم وأعدّل القرار إن اختلفا |
